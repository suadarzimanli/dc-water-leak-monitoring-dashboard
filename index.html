          How this dashboard works

          1. Start guide — interactive walkthrough at the top of the page (recommended for first-time users).
          2. Generate Data — loads 14 days of synthetic SCADA for 8 pressure zones.
          3. Train Model — trains a leak classifier in your browser, or use Rules only to compare.
          4. Live Simulation — new readings every few seconds; map and incidents stay in sync.
          5. Click a flagged zone → review context → follow workflow steps (Acknowledge → Ticket → Dispatch → Close).

          Zones at Risk counts map colors. Pending Review counts open incidents. They can differ when readings return to normal before an operator closes the case.
